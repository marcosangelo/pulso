# Código de conduta

Este projeto adota o [Contributor Covenant](https://www.contributor-covenant.org/pt-br/version/2/1/code_of_conduct/) versão 2.1.

## Nosso compromisso

Nós, como membros, colaboradores e líderes, nos comprometemos a fazer da participação neste projeto uma experiência livre de assédio para todos, independentemente de idade, deficiência, etnia, identidade ou expressão de gênero, nível de experiência, nacionalidade, aparência, raça, religião ou identidade e orientação sexual.

## Padrões

**Esperado:** linguagem acolhedora, respeito a pontos de vista diferentes, crítica construtiva, foco no que é melhor para a comunidade, empatia.

**Inaceitável:** linguagem ou imagens sexualizadas, trolling, insultos, assédio público ou privado, doxxing, outras condutas antiéticas.

## Aplicação

Reportes: abra uma issue privada ou use o [Security Advisory](https://github.com/marcosangelo/pulso/security/advisories/new) se o assunto for sensível. Líderes da comunidade podem remover contribuições que violem este código.

Há consequências proporcionais (aviso, ban temporário ou permanente), no espírito do Contributor Covenant.
